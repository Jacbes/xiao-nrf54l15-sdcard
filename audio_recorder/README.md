# XIAO nRF54L15 — запись звука с микрофона на SD-карту по кнопке

Прошивка для платы **Seeed Studio XIAO nRF54L15 (Sense)**: по кнопке включает/выключает
запись звука с цифрового PDM-микрофона и пишет её на microSD **частями (чанками)**.
Светодиод мигает во время записи. Проверено на железе — запись идёт корректно
(≈32 КиБ/с = 16 кГц, моно, 16 бит).

## Что делает прошивка (на каждой загрузке)

1. Ждёт, пока SD-карта ответит, и монтирует FAT.
2. **Самотест**: сразу записывает 3 с звука в `rec_XXXX.raw`, затем сканирует карту
   и печатает `>>> RECORDING TEST: OK` (или `FAIL`) — видно, что запись работает.
3. **Рабочий режим**: кнопка P0.00 переключает запись.
   - Старт → запускается микрофон, открывается `rec_XXXX.raw`, мигает LED P2.00.
   - Каждые 5 с текущий файл закрывается (`fs_sync`+`fs_close`) и открывается
     следующий — поэтому при отключении питания/карты **уже закрытые куски остаются целыми**.
   - Повторное нажатие → стоп (микрофон выключается, файл закрывается, LED гаснет).
   - При sporadic-сбое записи на нестабильной карте блок переписывается (до 3 попыток).

## Распайка

| Назначение | XIAO пин | nRF54L15 |
|------------|----------|----------|
| Кнопка     | BOOT     | **P0.00** |
| Светодиод  | LED      | **P2.00** |
| Микрофон CLK | —      | **P1.12** |
| Микрофон DAT | —      | **P1.13** |
| SD SCK     | D1       | P1.05    |
| SD MOSI    | D2       | P1.06    |
| SD MISO    | D3       | P1.07    |
| SD CS      | D0       | P1.04    |

Пины микрофона P1.12/P1.13 — родные пины PDM-периферии платы. Встроенный PDM-микрофон
Sense-версии питается от включённого при загрузке регулятора `pdm-imu-pwr`.

## Аудиоформат

Сырой PCM: **16 кГц, моно, 16 бит, little-endian** (без заголовка). Превратить в WAV:

```
ffmpeg -f s16le -ar 16000 -ac 1 -i rec_0001.raw rec_0001.wav
```

## ⚠️ Важно про SD-карту (особенность платы XIAO/nRF54L15)

SD-карта **не пере-питается** при софтверном сбросе МК (pyocd reset). Если карта
«зависла» (в логах `Card error on CMD0` повторяется бесконечно), восстановить её
программно нельзя — нужно **физически передёрнуть питание**: вытащить USB-кабель
платы (или саму SD-карту), подождать 2–3 с, вставить обратно. После «холодного»
старта карта инициализируется нормально. Это документированное поведение
(см. README корня репозитория → «Диагностика»).

SPI-частота понижена до **4 МГц** (вместо 8 МГц) — больше запаса по таймингам для
нестабильных карт; для аудио (32 КиБ/с) этого с огромным запасом хватает.

## Сборка

```
west build -b xiao_nrf54l15/nrf54l15/cpuapp audio_recorder -d audio_recorder/build -p always
```

(nRF Connect SDK v3.3.0, Zephyr 4.3.99).

## Прошивка

```
python -m pyocd flash -t nrf54l audio_recorder\build\audio_recorder\zephyr\zephyr.hex
```

## Настройка (начало `src/main.c`)

- `MIC_GAIN` — цифровое усиление микрофона (по умолчанию 32 ≈ +30 дБ). У PDM-периферии
  nRF нет аппаратного усиления — тихие записи усиливаются программно. Поставьте 64 или 128,
  если всё ещё тихо; поставьте 8 или 16, если звук искажается.
- `SELFTEST_SECONDS` — длительность загрузочного самотеста (по умолчанию 3 с; поставьте 0,
  чтобы отключить самотест и сразу перейти к режиму кнопки).
- `CHUNK_SECONDS` — длина одного файла-чанка (по умолчанию 5 с).
- `SAMPLE_RATE` / `CHANNELS` / `SAMPLE_BITS` — параметры звука (16 кГц / моно / 16 бит).
- `spi-max-frequency` в overlay — частота SPI к SD-карте (по умолчанию 4 МГц).
